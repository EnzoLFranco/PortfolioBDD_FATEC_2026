## 📝 Resumo do Projeto

O projeto consistiu no desenvolvimento de uma **Calculadora Científica via terminal**, projetada para atender necessidades contábeis e educacionais.

O desafio foi transpor a lógica de programação básica para uma ferramenta funcional capaz de lidar com:
- Operações aritméticas simples  
- Cálculos financeiros (juros)  
- Equações de segundo grau  
- Conversões de bases numéricas (Binário, Octal, Decimal e Hexadecimal)

---

## 💻 Tecnologias Utilizadas

- **TypeScript**  
  Linguagem principal utilizada para implementar lógica orientada a tipos, garantindo maior segurança e robustez nos cálculos.

- **Node.js**  
  Ambiente de execução utilizado para rodar a calculadora diretamente no terminal.

- **VisualG (Portugol)**  
  Utilizado na fase inicial de prototipagem para estruturar a lógica e os algoritmos fundamentais.

- **Git/GitHub**  
  Utilizados para controle de versão e organização de tarefas por meio do backlog do repositório.

---

## 🎯 Contribuições Individuais

Atuei no desenvolvimento do núcleo lógico da calculadora, com foco na precisão dos cálculos e na modularização do sistema.

- **Operações Aritméticas**  
  Implementação das funções de multiplicação e divisão, incluindo tratamento de erros para operações inválidas e entradas não numéricas utilizando validações com `isNaN`.  
  Estruturação da lógica de divisão, garantindo resultados precisos e bem formatados no terminal.

- **Função de Fatorial**  
  Desenvolvimento do algoritmo de fatorial utilizando estruturas de repetição, com validações para permitir apenas números inteiros e positivos.  
  Modularização da função para possibilitar sua reutilização de forma independente no menu principal.

- **Organização de Código**  
  Separação das responsabilidades do sistema, isolando regras de negócio da interface de navegação, melhorando a manutenção e a legibilidade do projeto em TypeScript.
