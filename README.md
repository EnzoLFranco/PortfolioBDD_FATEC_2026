# Portfólio de APIs – Banco de Dados | Enzo Lemos Franco

Este repositório apresenta o portfólio de projetos desenvolvidos ao longo da graduação em Tecnologia em Banco de Dados na Faculdade de Tecnologia de São José dos Campos (FATEC), utilizando a metodologia ágil Scrum e a abordagem de Aprendizagem por Projetos Integrados (API).

Por meio da API, cada semestre propôs um problema real trazido por uma empresa parceira, e a solução foi construída em equipe com entregas iterativas organizadas em sprints. Os projetos documentados aqui compõem parte dos requisitos acadêmicos para a obtenção do título de Tecnólogo em Banco de Dados e registram a evolução técnica e comportamental ao longo do curso.

Meu nome é Enzo Lemos Franco, tenho 20 anos e estou cursando o 6º semestre de Tecnologia em Banco de Dados na FATEC São José dos Campos, instituição em que ingressei no 1º semestre de 2024.

Ao longo do curso, desenvolvi conhecimentos sólidos em tecnologias, metodologias e boas práticas de desenvolvimento de software. A metodologia API foi central nessa trajetória: em cada semestre, trabalhei com empresas reais como clientes, o que me permitiu aplicar os conteúdos estudados em sala de aula na resolução de problemas concretos do mercado de trabalho.

Atualmente atuo como Aprendiz Administrativo na Cebrace, onde utilizo tecnologias como Python, SAP, Excel e Power BI para apoiar processos internos e gerar valor por meio de melhorias contínuas. Entre os projetos em andamento, desenvolvo uma solução de análise de dados de defeitos na produção: utilizando Python, extraio métricas de MTTR (Mean Time To Repair) e gero relatórios mensais que auxiliam a supervisão na identificação de falhas críticas e horários de maior ocorrência.

## Principais Conhecimentos

### Linguagens e Frameworks

| Tecnologia | Descrição |
|------------|-----------|
| **Java** | Desenvolvimento de APIs REST com Spring Boot, com foco em escalabilidade, persistência de dados com JPA/Hibernate e arquitetura em camadas |
| **TypeScript / JavaScript** | Desenvolvimento front-end com Vue.js e back-end com Node.js, com tipagem estática para maior segurança e robustez |
| **Python** | Automação de processos, scripts utilitários e análise de dados industriais |
| **Vue.js** | Desenvolvimento de interfaces interativas com Composition API, Pinia e integração com serviços back-end via Axios |
| **SQL** | Modelagem, manipulação e otimização de consultas em PostgreSQL, MySQL e Oracle |
