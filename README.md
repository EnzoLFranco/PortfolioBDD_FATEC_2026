## Portfólio de APIs – Banco de Dados | Enzo Lemos Franco

Este repositório apresenta o portfólio de projetos desenvolvidos ao longo da graduação , utilizando a metodologia ágil Scrum e a abordagem de Aprendizagem por Projetos Integrados (API) .

Os projetos reunidos aqui foram elaborados durante o curso de Tecnologia em Banco de Dados na Faculdade de Tecnologia de São José dos Campos (FATEC) e compõem parte dos  requisitos acadêmicos para a obtenção do título de Tecnólogo em Banco de Dados.

# Principais Conhecimentos

## Linguagens de Programação e Frameworks

**Java** para criação de APIs REST utilizando o Framework Spring Boot, com foco em escalabilidade e persistência de dados (JPA/Hibernate).

**Python**  para desenvolvimento de automações, scripts de melhoria de processos e análise de dados industriais.

**Vue.js** para construção de interfaces interativas e integração com serviços Back-End.

**SQL** para modelagem e manipulação de bancos de dados PostgreSQL e MySQL, além de conhecimento acadêmico em Oracle.
