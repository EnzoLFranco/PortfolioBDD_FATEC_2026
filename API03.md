## 📝 Resumo do Projeto

O Checkpoint foi desenvolvido para resolver problemas de gestão ineficiente de pontos de colaboradores terceirizados em estações de manutenção naval.

O sistema permite o controle detalhado da jornada de trabalho, vinculando funcionários a contratos específicos com prazos definidos.

A solução oferece um painel administrativo que possibilita a exportação de espelhos de ponto em formato `.csv`, com suporte a paginação personalizada, garantindo organização, rastreabilidade e conformidade operacional para a empresa parceira.

---

## 💻 Tecnologias Utilizadas

- **Java & Spring Boot**  
  Linguagem e framework utilizados para a construção de uma arquitetura de **APIs REST robusta**, responsável pelas regras de negócio da aplicação.

- **PostgreSQL**  
  Banco de dados relacional utilizado para garantir a integridade referencial entre empresas, contratos e registros de ponto.

- **Vue.js & Ant Design**  
  Stack de front-end utilizada para desenvolver uma interface administrativa com alto desempenho e componentes visuais padronizados.

- **Docker**  
  Utilizado para conteinerização da aplicação, garantindo consistência entre os ambientes de desenvolvimento e produção.

## 🎯 Contribuições Individuais

Atuei como Desenvolvedor Full-Stack, contribuindo tanto no front-end quanto no back-end do sistema.

- **Front-end (Vue.js)**: desenvolvimento da interface de gestão de funcionários, incluindo listagem com filtros, tela de edição, validações de formulários e melhorias de responsividade e experiência do usuário.

- **Back-end (Java / Spring Boot)**: refatoração do módulo de contratos, corrigindo problemas de persistência de dados no PostgreSQL e reestruturando entidades e relacionamentos JPA.

- **Arquitetura de dados**: implementação de DTOs para otimizar a comunicação entre front-end e back-end, reduzindo o volume de dados trafegados e melhorando a performance da aplicação.
